# Dodge Bomb

This project contains a playable Godot 4 prototype for a 2D bomb-survival game.

Features included:
- Main menu with Solo Mode, 2-Player Mode, and Player Colors
- Fullscreen launch configuration for Godot 4
- Player color palette using the exact hexadecimal values from the brief
- Physics-based bomb spawning, countdowns, and explosion knockback
- Survivability and elimination logic for solo and local two-player matches
- Speed Boost and Shield abilities
- Results screen with Retry and Main Menu actions

How to open:
1. Install Godot 4.x on your PC.
2. Open the folder containing `project.godot` in Godot.
3. Press F5 to run the project.

If `godot4` is installed locally, you can also validate with:

```bash
godot4 --headless --check-only
```

This environment does not provide a Godot runtime, so the project was created and structured to run locally on a machine with Godot installed.
